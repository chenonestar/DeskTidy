# DeskTidy 预研 Demo

验证《DeskTidy-需求说明》第 8 节的风险 1、4、5、6。技术栈与正式版一致：Wails v2（Go + WebView2），界面是一个无边框窗口，它本身就是被测试的“分组面板”。

## 运行前

- Windows 10 x64（1903 及以上）或 Windows 11，需要 WebView2 Runtime（系统一般已自带）。
- 普通用户权限即可，不需要管理员。
- 建议先截一张桌面截图，方便测试后对照图标位置。
- 绿色便携：所有数据写在程序旁边的 `demo-data\` 目录里（日志、状态、快照、WebView2 数据），删除整个目录即清理干净。

## 安全措施（测试过程中出任何问题都能回到原桌面）

| 情况 | 处理 |
|---|---|
| 正常退出 | 恢复系统图标、恢复面板模式、写回未恢复的图标位置 |
| 主程序崩溃或被结束 | 守护进程（同一个 exe，`--guard` 参数）发现后按 `demo-data\demo-state.json` 恢复 |
| 守护进程也不在了 | 双击 `恢复原桌面.cmd`；或者重启 Explorer / 注销，临时隐藏的系统图标会自己回来 |
| 风险 6 打乱图标后中断 | 守护进程按快照写回；也可以在界面点“按最新快照恢复”；另有注册表备份 `demo-data\snapshots\*-bags.reg` |

## 测试步骤

按界面上的标签页依次进行，每页都有“自动测试”和“手动检查清单”。所有结果会自动保存，程序被关掉后再打开仍在。

### 风险 1 · 面板挂桌面层

1. 依次选择 4 种模式：普通（对照组）、A 子窗口、B 拥有、C 置底。
2. 每选一种，点“自动测试当前模式”。它会模拟按 Win+D、点击测试按钮、在输入框输入 `desk`，然后再按一次 Win+D 还原窗口。约 5 秒，期间不要动鼠标键盘。如果其他窗口没有还原，自己再按一次 Win+D。
3. 按清单手动检查，特别是：
   - 中文输入法能否在面板里打字；
   - 重启 Explorer 后面板是否还在（任务管理器 → Windows 资源管理器 → 重新启动）。A、B 模式可能随 Explorer 一起被销毁，程序会退出，这本身就是要验证的结果；日志里会记下来，重新打开 Demo 即可继续。

### 风险 4 · 临时隐藏系统图标

1. 点“自动测试”：依次验证 SW_HIDE 隐藏、桌面刷新、全局刷新、用户切换“显示桌面图标”，以及退路方案（切换系统设置）能否隐藏和复原。约 15 秒，桌面图标会闪几下。
2. 点“临时隐藏系统图标”，再按清单手动检查：右键、双击、F5、改分辨率、新建文件、重启 Explorer、结束主进程。页面底部会记录每次 Explorer 重启后多久重新隐藏。

### 风险 5 · 内存

1. 依次点 ① 加载前测量 → ② 加载图标（默认 300 个）→ ③ 加载后测量 → ④ 静置 1 分钟后再测。
2. 打开任务管理器，把“DeskTidy Demo”这一组的内存数填到页面上。
3. 目标：常驻内存不超过 150 MB，空闲时 CPU 接近 0。

### 风险 6 · 图标位置

1. 如果桌面开了“自动排列图标”，先在桌面右键 → 查看中关掉，否则无法测试写回。
2. 点“自动测试”：拍快照并备份注册表 → 倒序打乱桌面图标 → 按快照写回 → 比对坐标。
3. 按清单确认图标完全复原；有多个显示器时请检查副屏。

### 生成报告

在“生成报告”页填写备注，点“生成并保存报告”。请把 `demo-data\DeskTidy-Demo-报告.md` 和 `demo-data\demo-log.txt` 发回来。

## 编译

- 在 Windows 上：运行 `build.cmd`。需要 Go 1.21 及以上，会自动下载 go.mod 要求的工具链。
- 在 Linux/macOS 上交叉编译：运行 `./build.sh`。

两种方式都不需要 Wails CLI 和 Node.js，输出在 `build\desktidy-demo.exe`。

## 代码结构

| 文件 | 内容 |
|---|---|
| `main.go` | 入口、单实例、守护进程、`--restore` |
| `app.go` | 绑定给前端的方法 |
| `panel.go` | 风险 1：三种挂桌面层的做法和自动测试 |
| `desktop.go` | 风险 4：定位桌面窗口、临时隐藏、事件钩子、Explorer 重启处理 |
| `icons.go`、`memory.go` | 风险 5：图标提取（IShellItemImageFactory → PNG）和进程树内存、CPU 统计 |
| `positions.go` | 风险 6：IFolderView 读写图标坐标、快照 |
| `state.go` | 日志和状态文件（先记录再修改） |
| `win32.go` | Win32 / COM 调用封装 |
| `frontend/index.html` | 测试界面 |
